# 一次審査の講評（対応が必要な点）

一次審査（アイデアコンペ）の講評のうち、対応や検討が必要な点だけを原文のまま載せたもの。評価された点や挨拶などは省略している（全文は `docs/materials/` の元資料を参照）。

- IDは参照用に付けたもので、元の講評にはない。欠番（F01・F04）は対応不要のコメントのため省略
- 評価された点の要旨: 提案の主要機能（階ずれの表現、屋内の文字案内、コンパス、シンプルな画面、バリアフリー、英語、管理画面）がおおむね全て評価された

## 改善・検討が必要な点

| ID | 内容 |
| --- | --- |
| F02 | 場所を案内する文章が誰にでも正確に伝わるよう、表現や言い回しを十分に検討し、実際の利用者による検証を重ねて改善してほしい。 |
| F03 | 利用者が自分の現在地を確認できる画面を設けることで、案内内容と実際の位置関係を把握しやすくなるのではないか。 |
| F05 | 建物内を経由する経路について、入口や階段、通路などをどのように案内するのか、具体的な誘導方法を更に検討してほしい。 |
| F06 | Go・MySQL を用いたサーバーを卒業後も誰が保守・管理するのか、継続的な運用体制を明確にしてほしい。また、管理画面の英語対応も検討してほしい。 |
| F07 | 情報の登録や更新など、管理者にかかる作業負担が大きくならないよう、管理方法の簡略化や負担軽減策を検討してほしい。 |
| F08 | 施設情報などの登録ミスが発生した場合に、誤りを発見・修正できる確認体制や対応方法を整備してほしい。 |
| F09 | 3D 表示について、建物の位置関係や経路を直感的に把握できるよう、視点や表示範囲、情報量などの見やすさを工夫希望 |

## プロトタイプ製作に向けて確認したい点

| ID | 内容 |
| --- | --- |
| P01 | 現在取り組んでいる課題の解決見通しと、完成したプロトタイプの具体的な操作感を確認できることを期待している。 |
| P02 | 実際の利用場面において 3D 地図が本当に必要なのか、通常の平面地図と比較しながら、視認性や操作性の面から検討希望。 |
| P03 | 低コストでの運用を掲げているが、初期開発費だけでなく、サーバー費用や保守・更新にかかる経費も含め、継続的に低コストで運用できるか明確にしてほしい。 |
| P04 | 管理画面を利用できる対象者や権限の範囲について、教職員全員が利用できるのか、一部の担当者に限定するのか、運用方針を明確にしてほしい。 |
| P05 | 初めて利用する人でも迷わず操作できるよう、初期画面にソフトの目的や基本的な使い方を説明する案内を設けてはどうか。 |
| P06 | サーバーを学内とクラウドのどちらに設置するのか、運用費用も含めて明確にしてほしい。また、利用する地図データの利用条件やライセンスについても確認が必要である |

## OBからの助言

| ID | 内容 |
| --- | --- |
| A01 | 「すでに動いている」部分が強みですが、初めて来る人が実際に迷わず着けるかは、これからの確認です。中間レビューで試す相手と成功の基準（例: 10 秒以内に探せる）を決めて測ると、さらに説得力が増します。「検証」を数字にしましょう。成功の目安を先に決めて試すと、結果が次の改善につながります。 |
