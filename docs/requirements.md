# 学内デジタルマップ 要求定義

2026年11月10日

コンペ側の要求をまとめたもの。根拠は募集要項の説明動画のスライド（`docs/materials/`、音声は未反映）。どう作るかは [proposal.md](proposal.md) を参照。

## 課題

キャンパスは校舎・実験棟・福利施設が点在し、地盤の高さも異なるため、目的地までの最適ルートが分かりにくい。

- 建物や施設の位置が、直感的に把握しにくい
- 案内板・紙媒体では情報が不足している
- 初めて来校する人が、スムーズに移動できない

迷いやすい具体例:

1. 3階 → 渡り廊下 → 2階（渡り廊下を渡ると階の数字が変わる）
2. 2棟2階へは別の棟から（目的の場所に、その棟の入口からは行けない）
3. 先生の部屋がどこか分からない

## 利用者

- **初めて来校する人**（動画で明示）。オープンキャンパス・多言語のアイデア例から、中学生・保護者や海外からの来校者も含むと読める
- **学生・教職員**（推定）。教室・研究室・教職員室を探す
- 導入先は北九州高専。学校で実際に活用され、DX推進・来校者の利便性向上・魅力発信につながることが求められる

## 審査項目（100点満点）

| 審査項目 | 配点 | 示すべきこと（読み取り） | 関係する要求 |
| --- | --- | --- | --- |
| 利用者目線での分かりやすさ | 25 | 初めて来校する人が、説明なしで使えて目的地に着けること | R01、R02、R06、R08、R14 |
| 課題・目的の明確さ | 20 | どの「迷う」状況を、誰のために解くのかがはっきりしていること | R03〜R07 |
| 独自性・アイデア性 | 20 | 案内板・紙媒体やアイデア例を並べただけのものとの違い。審査に特許事務所が加わるため、何が新しいかを説明できること（推定） | R15 |
| 継続運用のしやすさ | 20 | 作った学生が卒業した後も、部屋や担当の変更に対応して使われ続けること | R09、R12、R13 |
| 実現可能性 | 15 | 3月中旬までに、制作支援費の範囲で完成・納品できること | R15、R16 |

## 制約

| 項目 | 内容 |
| --- | --- |
| 期間 | プロトタイプ制作は11月〜12月、1月中旬に中間レビュー、2月下旬〜3月中旬に最終発表会 |
| 予算 | 制作支援費は1チームあたり5万円 |
| 納品 | 賞金は成果物の完成と納品が条件 |
