# 学内デジタルマップ 要求定義（募集要項の説明動画より）

2026年11月10日

## 概要と前提

募集要項の説明動画が求めているのは、「誰もが迷わず目的地へ行ける学内デジタルマップ」を、学校で実際に使われ続ける形で完成・納品することです。このドキュメントは、動画からその要求を抜き出したもので、どう作るか（提案や機能の設計）は含みません。

- **根拠**: 動画（約6分、`docs/materials/コンペ説明動画.mp4`）に映るスライド10枚の文字。出典欄の時刻は、そのスライドが映る動画の位置です。
- **含めていないもの**: 動画の音声による説明。音声でだけ話された条件があれば、[未確認事項](#未確認事項)に足してください。
- **要求の種類**:
  - **明示**: スライドにそのまま書かれているもの
  - **課題から**: スライドの課題を裏返して要求にしたもの
  - **推定**: スライドには書かれていないが、内容から読み取れるもの

## 解くべき課題

迷う原因は、校舎・実験棟・福利施設が点在し、地盤の高さも異なる広大なキャンパスにあります。そのため、目的地までの最適ルートが分かりにくい場面が多い、と動画は説明しています。

| 課題 | スライドの説明 | 出典 |
| --- | --- | --- |
| 目的地が分かりにくい | 校内の建物や施設の位置が、直感的に把握しにくい | 0:54 迷いやすさの現状と課題 |
| 案内板・紙媒体だけでは不十分 | 情報が不足しており、対応しきれていない | 0:54 迷いやすさの現状と課題 |
| 迷ってしまう | 初めて来校する人が、スムーズに移動できない | 0:54 迷いやすさの現状と課題 |

迷いやすい具体例として、次の3つが挙がっています（0:36 広大なキャンパスと案内の課題）。

1. 3階 → 渡り廊下 → 2階！？（渡り廊下を渡ると階の数字が変わる）
2. 2棟2階へは別の棟から！？（目的の場所に、その棟の入口からは行けない）
3. 先生の部屋・・・どこ！？（教職員の部屋の場所が分からない）

括弧内は、スライドの一言を言い換えたものです。

## 制約条件

一番重い制約は、納品までの期間と制作支援費です。プロトタイプの賞金は、成果物の完成と納品が条件です。

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 参加資格 | 北九州工業高等専門学校の学生。個人・チームどちらも可 | 2:06 募集対象とテーマ |
| 制作期間 | プロトタイプ制作は11月〜12月、1月中旬に中間レビュー、2月下旬〜3月中旬に最終発表会 | 3:24 スケジュール |
| 制作支援費 | 最大3チームに、1チームあたり5万円 | 4:36 賞金と制作支援 |
| 納品 | 賞金（最優秀10万円・優秀5万円・奨励2万円）は、成果物の完成と納品が条件 | 4:36 賞金と制作支援 |
| 審査員 | 教員・職員・後援会・同窓会・弁理士法人安倍・下田国際特許事務所 | 4:36 賞金と制作支援 |
| 問い合わせ先 | 電気電子コースの担当教員（氏名は元資料を参照） | 5:06 応募方法・問い合わせ先 |

実現の手段（2D、3D、AR、写真や動画など）は、スライド上では指定されていません。

## 審査項目から読み取れる要求

配点が最も高いのは「利用者目線での分かりやすさ」の25点です。「継続運用のしやすさ」は「実現可能性」の15点より重く、20点です（2:48 審査項目と配点）。「示すべきこと」の列は、配点とスライドの内容から読み取ったものです。

| 審査項目 | 配点 | 示すべきこと（読み取り） | 関係する要求 |
| --- | --- | --- | --- |
| 利用者目線での分かりやすさ | 25点 | 初めて来校する人が、説明なしで使えて目的地に着けること | R01、R02、R06、R08、R14 |
| 課題・目的の明確さ | 20点 | どの「迷う」状況を、誰のために解くのかがはっきりしていること | R03〜R07 |
| 独自性・アイデア性 | 20点 | 案内板・紙媒体や、アイデア例を並べただけのものとの違い。審査に特許事務所が加わるため、何が新しいかを説明できること（推定） | R15 |
| 継続運用のしやすさ | 20点 | 作った学生が卒業した後も、部屋や担当の変更に対応して使われ続けること | R09、R12、R13 |
| 実現可能性 | 15点 | 3月中旬までに、5万円の制作支援費の範囲で完成・納品できること | R15、R16 |

## スケジュール

第2段階は、制作に使える期間が11月〜12月の約2か月で、最終発表会まで含めても約4か月です。
